## 🚀 Sobre Mí

Soy **Desarrollador de Software** ubicado en **Ocaña, Norte de Santander (Colombia)**. Me apasiona diseñar y construir soluciones tecnológicas eficientes, desde aplicaciones web modernas y arquitecturas modulares hasta flujos automatizados con **n8n** e integración de modelos de **Inteligencia Artificial Generativa**.

- 💡 **Filosofía de desarrollo:** Soluciones simples, mantenibles y orientadas a valor de negocio real.
- ⚙️ **Enfoque técnico:** Código modular (Single Responsibility Principle), optimización de rendimiento de red (evitando cuellos de botella y cascadas N+1) y pruebas automatizadas.
- 🗣️ **Idiomas:** Español (Nativo) · Inglés (Técnico / Intermedio).
